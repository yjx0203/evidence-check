When does a 5 × 5 input produce a 5 × 5 output with a 3 × 3 convolution kernel?

Simulated AI claim

Cited passage

With no dilation and equal padding on both sides of an axis, use the following formula for the output size along that axis.

Output size = ⌊(N + 2P − K) / S⌋ + 1

Source details and symbols

Convolution output size, section 1. Teaching note written for this prototype.

N = input size, P = padding on each side, K = kernel size, S = stride. The floor brackets round down to an integer.
